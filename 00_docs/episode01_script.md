# SCENE 1. 필경실 아침
**길이 1:40 / 페이지 p001 / 시간 아침 7시경 / 장소 수도원 필경실**

### 목적
- 수도원의 분위기 확립
- 마리의 그림 실력 제시
- 안나와의 관계 (편안하고 가까움)
- **쑥부쟁이 그림 소개** = 1화의 중심 소품

### 연출 메모
- 창문으로 들어오는 **긴 아침빛 기둥**. 먼지가 빛 속에서 떠다님
- 양피지, 잉크병, 붓, 마른 약초 다발의 질감 대비
- 다른 수녀들은 **글씨를 베끼는 반복 노동**. 마리만 **그림**을 맡고 있음
- 소리: 깃펜 긁는 소리, 종이 넘기는 소리. 대사 전까지 약 15초간 대사 없음
- 마리는 숙여 있고, 안나는 몸을 기울여 마리의 메모를 들여다본다

### 대사
```
(15초간 무대사 — 필경실의 아침)

안나      마리 수녀님, 이 풀 이름이 뭐라고요?
마리      거기 적어뒀는데요.
안나      네. 그걸 읽고 있는데요.

(안나가 메모를 코앞까지 들어 올린다)

안나      이 두 글자, 같은 글자예요?
마리      네. 둘 다 '뿌리'요.
안나      하나는 '뿔' 같은데요.

(마리의 손이 멈춘다 — 붓을 쥔 손가락에 잉크 자국)

마리      손이 시려서요.
안나      오늘 안 춥잖아요.
마리      어제 쓴 거예요.

(안나가 웃음을 참는다. 마리는 못 본 척 붓을 다시 든다)
```

### 감정 상태
- 마리: 평온 → 살짝 머쓱함 (들켰지만 인정하지 않음)
- 안나: 호기심 → 다정한 놀림 (교태 아님, **친구 같은 놀림**)

### 하이라이트 컷
- **마리가 그린 쑥부쟁이 도해 전체** (크게) — 다섯 장의 꽃잎이 또렷하게 그려진 그림
- 이 컷이 1화 전체의 "틀린 그림"이다. 관객이 나중에 되돌아볼 컷이므로 **반드시 크게**

# SCENE 2. 베르타의 등장
**길이 1:25 / 페이지 p002 / 장소 필경실 (연속)**

### 목적
- **도감 오류의 씨앗** 심기
- 베르타의 권위 확립
- 마리의 불안 점화

### 연출 메모
- 등장 예고: **열쇠 꾸러미 소리** (화면에 베르타는 아직 없음) → 수녀들이 일제히 자세를 고침
- 베르타는 말하기 전에 **그림을 오래 내려다본다** (침묵 2초)
- 베르타의 **왼손 화상 흉터**가 그림 위에 놓이는 순간을 인서트로 (복선)
- 조명 변화: 따뜻한 금빛 → 베르타의 그림자가 책상을 덮으며 서늘해짐
- 마지막 대사 후 베르타는 바로 나간다. **답을 주지 않는다**

### 대사
```
(열쇠 꾸러미 소리. 수녀들의 등이 펴진다)

베르타    이게 뭐냐.
마리      쑥부쟁이요.

(베르타가 도감을 집어 든다. 왼손 흉터가 양피지 위를 스친다)

베르타    이 책은 백 년 전 거다.
베르타    이걸 그린 사람도 누군가를 베꼈겠지.
베르타    그 사람도 또 누군가를 베꼈을 테고.

(침묵)

베르타    실제 쑥부쟁이는 그렇지 않아.
마리      …그럼 몇 장인데요?
베르타    나도 모른다.

(돌아서며)

베르타    틀린 그림을 보고 틀린 풀을 캐면, 사람이 죽어.

(문이 닫힌다. 안나와 마리만 남는다. 무대사 3초)
```

### 감정 상태
- 베르타: 평온한 단호함. **화내지 않는다**
- 마리: 반박 → 질문 → **대답을 못 받은 공백**
- 안나: 긴장. 숨을 죽이고 있음

### 하이라이트 컷
- "틀린 그림을 보고 틀린 풀을 캐면, 사람이 죽어." — **크게**, 베르타의 뒷모습 + 마리의 얼굴 반응

# SCENE 3. 약초 건조실
**길이 1:05 / 페이지 p003 / 장소 수도원 약초 건조실**

### 목적
- 마른 약초와 살아 있는 약초의 차이를 **몸으로** 확인
- 수도원 기록의 한계
- **안나의 숲에 대한 두려움 최초 노출**

### 연출 메모
- 천장에 거꾸로 매달린 약초 다발 수십 개. 역광
- 공기 중 먼지 + 마른 약초 가루
- 마리가 마른 쑥부쟁이를 손에 쥐자 **부스러진다** → 꽃잎을 셀 수 없다
- 엘제는 작업을 멈추지 않고 대답한다 (일손이 계속 움직임)
- 안나의 "…네." 에서 **1초 공백**. 시선이 바닥으로 내려간다

### 대사
```
마리      쑥부쟁이 있어요?
엘제      마른 것밖에 없다.
마리      꽃은요?
엘제      떨어졌지.

(마리가 마른 줄기를 쥔다. 손안에서 부스러진다)

마리      살아 있는 건 어디 있어요?
엘제      동쪽 숲.

(마리가 안나를 돌아본다)

마리      안나 수녀님, 숲에 가봤어요?
안나      아뇨.
마리      무서워요?

(안나의 시선이 내려간다)

안나      …네.
마리      그럼 혼자 가진 않을게요.
```

### 감정 상태
- 마리: 확인 → 결심의 전조
- 안나: 평온 → **들킴** → 안도 (마리가 강요하지 않음)
- 엘제: 무심. 사실만 전달

### 하이라이트 컷
- **부스러지는 마른 쑥부쟁이를 쥔 마리의 손** (클로즈업, 크게) — 꽃잎을 셀 수 없다는 시각적 증명

# SCENE 4. 회랑과 약속
**길이 0:50 / 페이지 p004 / 장소 수도원 회랑 / 시간 정오 전**

### 목적
- 안나와 마리의 관계를 **부드럽게** 진전
- 안나의 두려움에 **과거의 그림자**가 있음을 암시 (회수는 후반 화)

### 연출 메모
- 아치형 회랑. 기둥 사이로 빛과 그림자가 교대로 지나감
- 두 사람이 **걸으며** 대화. 정지 샷으로만 처리하지 말 것
- 안나의 대사 중 한 번 **멈춘다**. 마리도 멈춘다 → 발 인서트 2컷
- 안나의 "저도 같이 가요." 에서 처음으로 **눈을 마주본다**

### 대사
```
안나      제가… 그 숲에 다시는 가지 않겠다고 한 것도… 그 때문이에요.
마리      ……그렇군요.

(둘 다 걸음을 멈춘다)

안나      무섭지만… 그림으로는 계속 그리고 싶다… 그런 거죠?
마리      …네.
안나      이상하죠?
마리      전혀요.
마리      두려운 대상일수록 더 알고 싶고… 더 그리고 싶어지거든요.

(안나가 마리를 본다)

안나      언젠가 괜찮아질 때가 오면… 저도 같이 가요.
마리      …같이요?
안나      네. 그때는 이번에 제가 용기를 낼 테니까.
```

### 감정 상태
- 안나: 조심스러운 고백 → 결심
- 마리: 듣기 → 공감 → 미세한 놀람 (같이 간다는 말에)

### 하이라이트 컷
- **두 사람이 처음 눈을 마주보는 컷** (크게) — 역광 회랑, 기둥 사이 빛

### 주의
- 로맨스로 과하게 기울이지 말 것. **아직은 신뢰의 단계**
- 손을 잡거나 스킨십 금지

# SCENE 5. 숲길과 실제 쑥부쟁이
**길이 1:10 / 페이지 p005 / 장소 동쪽 숲 입구 ~ 숲길 / 시간 오후**

### 목적
- 수도원 밖의 생생한 자연 제시
- 마리의 **관찰 본능** 발동
- **책과 현실의 차이**를 관객이 직접 보게 함

### 연출 메모
- 수도원의 닫힌 공기 → 숲의 열린 공기. **색온도와 채도를 확 바꿈**
- 익스트림 롱샷으로 숲의 규모를 먼저 제시
- 안나는 반 발 뒤에서 걷는다. 치맛자락을 쥐고 있음
- **실제 쑥부쟁이 컷이 이 페이지의 핵심**:
  - p001의 "다섯 장의 꽃잎" 도해와 **나란히 비교되도록** 구도를 맞춘다
  - 실제 꽃은 더 풍성하고, 가느다란 설상화가 수십 장, 중심에 노란 통상화 뭉치
- 마리는 무릎을 꿇고 스케치북을 꺼낸다. 베일이 흘러내림

### 대사
```
마리      숲이… 생각보다 조용하네요.
안나      조용한 게 더 무서울 때도 있어요.

(마리가 걸음을 멈춘다. 바닥을 본다)

마리      안나 수녀님, 보세요.
마리      이게 진짜 쑥부쟁이예요.

(실제 꽃 — 크게)

안나      정말이네요… 도감 그림이랑은 전혀 달라요.
마리      이렇게 직접 봐야만 알 수 있군요.

(마리가 스케치를 시작한다. 안나는 곁에 앉아 지켜본다. 무대사 4초)
```

### 감정 상태
- 마리: 긴장 → **발견의 몰입**
- 안나: 경계 → 마리를 지켜보는 안온함

### 하이라이트 컷
- **실제 쑥부쟁이 익스트림 클로즈업** (최대 크기) — 설상화가 셀 수 없이 많다는 것이 보여야 함

# SCENE 6. 숲의 흔적과 마녀의 첫 등장
**길이 1:20 / 페이지 p006 / 장소 숲 안쪽**

### 목적
- 숲에 **다른 누군가**가 있다는 암시
- **에스텔의 첫 등장** (2막 전환점)
- 숲의 지식이 수도원 밖에 있음을 제시

### 연출 메모
- 흔적 인서트 3연타 (작게):
  1. 줄기가 **칼이 아니라 손으로 비틀려 꺾인** 자리 — 수도원은 칼로 자른다
  2. 땅에 눌린 **무릎 자국**
  3. 나뭇가지에 묶인 **색실** (보라색 — 에스텔의 색)
- 안나의 "이제 돌아갈까요…?" 에서 바람이 불고 **잎 소리**
- **에스텔은 오프 보이스로 먼저 등장** → 그 다음 컷에서 전신 공개
- 첫 등장 컷 = **페이지 최대 컷.** 단, 위압적 로우앵글 금지.
  → 눈높이 또는 살짝 아래. 나무에 기대 서 있거나 바위에 앉아 있음. **호흡이 풀리는 느낌**
- 모자 챙의 야생화에 빛이 걸린다

### 대사
```
안나      저건… 뭐죠?

(흔적 인서트 3컷)

마리      수도원 방식이 아니에요.
마리      누군가 여기 있었어요.

(바람. 잎 소리)

안나      이제 돌아갈까요…?

에스텔(오프)   좋은 질문이네.

(두 사람이 돌아본다 — 에스텔 전신 공개, 최대 컷)

에스텔    그 꽃이 궁금해서 여기까지 온 거지?
```

### 감정 상태
- 마리: 추리 → 경계 → 압도되지 않는 호기심
- 안나: 두려움 최고조 → 마리 쪽으로 반 발 이동
- 에스텔: 여유. **적대감 없음.** 재미있어 하는 눈

### 하이라이트 컷
- **에스텔 전신 첫 등장** (페이지 최대) — 보랏빛 모자, 야생화, 숲빛

### 주의
- 도적처럼 보이면 즉시 재생성
- 내려다보는 위압 포즈 금지

# SCENE 7. 에스텔의 설명
**길이 1:10 / 페이지 p007 / 장소 숲 안쪽 (연속)**

### 목적
- "그 꽃을 그렇게 세는 게 아니다"의 **실제 의미**를 자연스럽게 전달
- 설명충 금지 — **마리의 관찰을 열어주는 방식**

### 연출 메모
- 에스텔이 꽃을 꺾지 않는다. **손바닥으로 받쳐 들어 보여준다**
- 설명 중 카메라는 **꽃과 마리의 눈을 번갈아** 본다 (에스텔 얼굴 고정 금지)
- 마리의 깨달음은 대사가 아니라 **눈이 커지는 컷 + 스케치북을 덮는 손**으로
- 안나는 옆에서 듣지만 **아직 긴장이 완전히 풀리지 않음** (손을 모아 쥐고 있음)
- 에스텔은 이 씬에서 자세를 2번 바꾼다 (쪼그려 앉음 → 일어서며 손짓)

### 대사
```
에스텔    그거, 한 송이처럼 보여도 진짜로는 작은 꽃들이 모인 거야.

(꽃 — 익스트림 클로즈업. 설상화 하나하나가 보인다)

에스텔    책 그림은 겉모양만 흉내 내기 쉬워.
에스텔    살아 있는 걸 보지 않으면,
```

# SCENE 9. 잘못된 약초
**길이 1:10 / 페이지 p009 / 장소 숲 안쪽 (연속)**

### 목적
- **베르타의 경고가 현실 문제로 전환**
- 에스텔의 실력 증명
- 마리의 충격

### 연출 메모
- 바구니 안을 위에서 내려다보는 **탑샷** (중요) — 잘못된 풀이 보인다
- 에스텔이 풀을 들어 올려 **쑥부쟁이와 나란히** 놓는다 → 비교 컷 (크게)
  - 닮은 점: 전체 실루엣, 꽃 색
  - 다른 점: 잎 모양, 줄기 단면, 꽃 중심부
- "속부터 망가질 수도 있어" 에서 **마리의 손이 자기 스케치북을 쥔다** (p001 그림 회상 암시)
- 마리의 회상 플래시: p001의 "다섯 장의 꽃" 도해 1컷 (작게, 색 빠진 톤)
- 안나의 대사는 **조용하게**. 비명 금지

### 대사
```
소년      이거 맞죠? 수도원 책 보고 캤어요.

(탑샷 — 바구니 안)

에스텔    아니. 이건 아니야.
마리      왜요?

(에스텔이 두 풀을 나란히 든다 — 비교 컷, 크게)

에스텔    비슷해 보여도 달라.
에스텔    이걸 달여 먹이면 열은 못 잡고, 속부터 망가질 수도 있어.

(마리의 손이 스케치북을 쥔다 / 플래시 — 다섯 장의 꽃 도해)

안나      …정말 죽을 수도 있는 거네요.
에스텔    그래서 보는 법을 잘못 배우면 안 되는 거야.
```

### 감정 상태
- 소년: 자신 있음 → 무너짐
- 에스텔: 단호. 아이를 책망하지 않음 → **책을 책망한다**
- 마리: 충격. 자기 그림이 떠오름
- 안나: 서늘한 이해

### 하이라이트 컷
- **두 풀을 나란히 든 비교 컷** (크게)
- **마리의 충격 (얼굴 또는 스케치북을 쥔 손)** (크게)
