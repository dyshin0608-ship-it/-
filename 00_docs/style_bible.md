# STYLE BIBLE — 《숲의 약방》 / The Forest Apothecary

> 이 문서는 **모든 이미지 생성의 최상위 규칙**이다.
> 프롬프트, 모델, 워크플로우가 바뀌어도 이 문서가 기준이다.
> 결과물이 이 문서와 충돌하면 → **결과물을 버리고 재생성**한다.

---

## 0. 한 줄 정의

> **종이 위에 손으로 그린, 유화·수채·잉크가 섞인 따뜻한 판타지 회화풍 만화.**
> 회화적 조명과 손그림 컷선을 가진 "동화책과 컨셉아트 사이".

---

## 1. 스타일 핵심 (STYLE CORE)

### 1-1. 반드시 있어야 하는 것 (MUST HAVE)

| 요소 | 기준 |
|---|---|
| 붓자국 | 육안으로 보여야 함. 머리카락·옷주름·배경 식물에 스트로크 방향이 읽힘 |
| 종이 질감 | 미세한 입자감. 수채 종이의 올이 은은하게 느껴짐 |
| 혼합 매체 | 유화의 두께 + 수채의 번짐 + 잉크의 선 + 색연필의 거친 결 |
| 컷 경계선 | 자 대고 그은 선 금지. 손으로 그은 떨림이 있는 선 |
| 조명 | 회화적. 광원이 명확하고 공기감(aerial perspective)이 있음 |
| 재질 구분 | 피부 / 리넨 / 모직 / 머리카락 / 돌벽 / 양피지 / 마른 약초가 각기 다른 터치 |
| 성숙한 미술성 | 유치하지 않음. 아동 그림책 아님 |

### 1-2. 절대 금지 (HARD BAN)

- 번들거리는 플라스틱 표면 / 에어브러시 광택
- 3D 렌더 느낌, 서브서피스 스캐터링 과다, CG 하이라이트
- "광택 심한 AI 미소녀 일러스트" 톤
- 로맨스 판타지 표지풍 과장 (과한 블룸, 렌즈 플레어, 반짝이 입자 남발)
- 디지털 필터로 긁은 듯한 과도한 샤프닝
- 실사화 / 사진 합성 느낌
- 페이지마다 그림체가 달라지는 것
- AI 특유의 동일 표정·동일 구도 템플릿 반복
- 글자·문자를 AI가 직접 그린 것 (→ 전부 후처리)

### 1-3. 참고 느낌 (직접 모사 금지, 재해석만)

- **아케인**: 회화적 조명, 묵직한 질감, 색으로 감정을 칠하는 방식
- **스파이더버스**: 그래픽 감각의 컷 연출, 리듬, 과감한 레이아웃
- → 위 두 개는 **"감각"만 참조**. 캐릭터 디자인·색조·브러시는 본작 고유 스타일로.
- 더 중요한 축: **손그림의 따뜻함, 회화성, 컷 분할의 감각**

## 2. 질감 규칙 (TEXTURE)

### 2-1. 허용 범위
- 잉크 번짐 (bleed) — 소량
- 마른 붓 (dry brush) — 돌벽, 나무, 마른 약초에 적극 사용
- 물 먹은 종이 (wet-on-wet) — 하늘, 안개, 숲 원경
- 색연필 결 — 그림자 경계, 옷 주름 보조
- 긁힌 질감 (scratch) — 양피지, 낡은 도감

### 2-2. 선
- 또렷한 만화 선화(clean lineart) **아님**
- 약간 흐트러진 손드로잉 + 채색 일체형
- 선과 색이 완전히 일치하지 않음 (의도된 어긋남 허용, 과하면 안 됨)
- 선 굵기 변화 있음 (필압)

### 2-3. 선명도
- 전체가 균일하게 선명하면 실패
- 주피사체 선명 → 중경 부드러움 → 원경 번짐
- 단, 예쁘되 **지저분하면 안 된다**. 더러움·얼룩·노이즈는 금지.

### 3-3. 채도 규칙
- 너무 튀지 않게. 단, 밋밋해도 실패.
- 하이라이트 컷 1곳에만 **채도 피크**를 허용 (예: 에스텔 첫 등장의 보라, 실제 쑥부쟁이의 연보라)
- 한 페이지 안에서 색온도가 통일되어야 함 (장면 전환 시에만 변경)

## 4. 컷 분할 규칙 (요약 — 상세는 `page_layout_rules.md`)

1. **하이라이트 컷은 크게** — 감정 폭발 / 발견 / 중요 대사 / 첫 등장 / 분위기 확립
2. **연결 컷은 작게** — 손, 발, 소품, 시선 이동, 약초 디테일, 책·양피지
3. **패널 모양은 비정형** — 직사각형만 반복 금지. 손으로 찢은 듯한 테두리 허용
4. **읽는 순서는 반드시 명확** — 예쁨보다 가독성 우선
5. **샷 다양성 필수** — 바스트샷 2연속 금지
6. **감정은 표정·손·시선·침묵으로** — 나레이션 남발 금지

---

## 5. 말풍선 규칙 (요약 — 상세는 `speech_bubble_rules.md`)

- 텍스트는 **AI 이미지에 직접 생성하지 않는다.**
- 그림은 textless로 생성 → 별도 레이어로 한국어 합성
- 생성 시 **말풍선 안전영역(bubble safe area)** 을 비워 둔 구도로 프롬프트 작성

## 6. 스타일 드리프트 방지 (CRITICAL)

### 6-1. 고정 자산
- `01_references/style_anchor_01.png` ~ `style_anchor_06.png` — 스타일 기준 이미지
- `01_references/*_sheet.png` — 캐릭터 시트
- `06_prompts/prompt_templates.md` 의 **STYLE_BLOCK 문자열은 수정 금지**
- 모델 / VAE / 샘플러 / CFG / 스케줄러 / LoRA 가중치는 **episode 단위로 동결**

### 6-2. 매 컷 생성 시
1. STYLE_BLOCK을 프롬프트 선두에 고정 삽입
2. 해당 컷 등장 캐릭터의 시트를 레퍼런스로 투입 (IP-Adapter / reference)
3. 직전 페이지 1장을 스타일 앵커로 추가 투입 (낮은 가중치)

### 6-3. 재생성 트리거 (하나라도 걸리면 폐기)
- 마리 얼굴이 다른 사람처럼 보임
- 안나의 체형이 갑자기 마르거나 평평해짐
- 에스텔이 도적/암살자처럼 보임
- 광택이 플라스틱처럼 올라옴
- 붓자국이 사라지고 매끈해짐
- 컷 경계선이 자로 그은 직선이 됨
- AI가 글자를 그려 넣음

## 7. 해상도 / 출력 규격

| 단계 | 해상도 | 비고 |
|---|---|---|
| 컷 1차 생성 | 832×1216 또는 1024×1536 | 세로 컷 기준 |
| 가로 와이드 컷 | 1344×768 | 익스트림 롱샷용 |
| 컷 업스케일 | ×1.5 ~ ×2 | 질감 보존 업스케일러 사용 |
| 최종 페이지 | 1536×2304 이상 | 세로형 페이지 |
| 납품본 | 2048×3072 | 인쇄 여유 |

- 업스케일 시 **질감이 뭉개지면 실패**. 디테일 복원형 업스케일러보다 질감 보존형 우선.

---

## 8. 톤 & 연출 원칙

- 다크 판타지 일변도 아님. **서늘한 미스터리 + 따뜻한 감정 공존**
- 아름답고 서정적인 장면이 많아야 함
- 과장된 설명보다 **보여주는 연출**
- 대사는 짧고 자연스럽게. **설명충 금지**
- 침묵 컷(대사 없는 컷)을 페이지당 최소 1개 확보
