# 1. 마리 (Marie) — 주인공

## 고정 외형 (FIXED)
- 22세 / 158cm / 수도원의 그림 그리는 수녀 (필경실 도해 담당)
- **머리**: 긴 흑발. 약간 젖은 듯 자연스럽게 흐르는 결. 윤기는 있으나 광택은 과하지 않음
- **눈**: 황갈색 / 호박빛 (amber). 눈매는 또렷하지만 날카롭지 않음
- **얼굴**: 섬세하고 청초. 턱선 얇음. 코·입 작고 섬세. 조용한 미인
- **인상**: 귀엽지만 차분하고 **서늘한 분위기**. 센 인상 금지
- **체형**: 날씬한 편. 지나치게 글래머러스하면 안 됨
- **의상**: 회갈색~보랏빛이 도는 작업복 계열 수도복. 흰 리넨 베일. 소매를 걷어 올린 경우가 많음
- **시그니처**: **손가락 끝과 손등에 잉크 자국.** 모든 손 인서트 컷에 필수

## 표정 규칙
- 표정 변화의 폭이 작다. **눈빛이 전부**
- 놀랄 때도 입을 크게 벌리지 않음 → 눈이 커지고 숨이 멈춤
- 웃음은 입꼬리 아주 조금
- 감정이 커질 때는 **손이 먼저 반응** (붓을 쥐는 힘, 옷자락을 쥠)

## 포즈 레퍼토리 (반복 방지)
그림 그리는 자세(숙임) / 붓을 씻는 손 / 식물에 얼굴을 가까이 대고 관찰 / 쪼그려 앉아 스케치 /
걷다가 멈춰 뒤돌아봄 / 베일을 고쳐 쓰기 / 무릎에 스케치북 / 손끝으로 잎을 만짐

## 말투
조용하고 짧고 신중함. 감정이 커도 절제됨. 존댓말.
- O: "어제 쓴 거예요." / "…그럼 몇 장인데요?" / "그럼 혼자 가진 않을게요."
- X: 길게 설명하는 대사, 감탄사 남발, 들뜬 말투

## 프롬프트 태그 (고정)
```

delicate quiet beautiful face, thin jawline, small refined nose and lips,
calm cool composed expression, greyish-brown purple-tinted working habit,

```

## 금지
- 글래머러스한 강조
- 활짝 웃는 과장된 표정
- 계속 숙인 자세만 반복

# 2. 안나 (Anna)

## 고정 외형 (FIXED)
- 24세 / 162cm / 마리 옆자리 수녀 (필경 담당)
- **머리**: 금발. 풍성한 곱슬 또는 웨이브. 베일 밖으로 잔머리가 몇 가닥 흘러나옴
- **눈**: 밝은 파랑~회청색. 둥글고 큰 눈
- **얼굴**: 둥근 얼굴. **볼이 발갛고 사랑스러움**. 부드러운 윤곽
- **체형**: 육덕지고 풍만한 성인 여성 체형. 가슴·허리·엉덩이의 볼륨이 느껴지는 건강한 몸.
  → **방향성: "건강하고 따뜻하고 포근한" 풍만함.**
  → 저속·노골 금지. 가슴 강조 앵글 금지. 옷을 몸에 들러붙게 그리지 말 것.
  → 수도복은 **넉넉한 리넨**. 체형은 실루엣과 어깨·허리의 곡선으로 전달
- **의상**: 크림색 수도복. 베일에 아주 연한 꽃무늬 또는 부드러운 패턴 허용
- **시그니처**: 손이 통통하고 따뜻해 보임. 소매 끝에 잉크 한 방울

## 성격 / 감정 아크
- 친근하고 호기심 많고 다정함
- **초반엔 장난기보다 "궁금해서 묻는" 느낌**
- 유혹하는 캐릭터처럼 보이면 안 됨. 교태 금지
- **숲 이야기가 나오면 미묘하게 주저하고 두려움이 드러남** (1화의 핵심 복선)
  → 시선을 피함 / 손을 모아 쥠 / 말끝을 흐림 / 어깨가 살짝 안으로 말림

## 포즈 레퍼토리 (반드시 다양화 — 반신샷 반복 금지)
책상에 턱 괴기 / 몸을 기울여 마리 쪽으로 / 양손을 모아 쥐기 / 의자에 비스듬히 기대기 /
걷다 멈추기 / 치맛자락을 쥐고 숲을 보기 / 쪼그려 앉아 마리 옆에서 지켜보기 /
베일 끈을 만지기 / 뒤돌아 어깨만 보이기 / 마리의 소매를 살짝 잡기

## 말투
부드럽고 친근함. 호기심 많음. 존댓말. 짧은 물음표 대사가 많다.
- O: "이 두 글자, 같은 글자예요?" / "오늘 안 춥잖아요." / "조용한 게 더 무서울 때도 있어요."
- X: 꼬시는 듯한 대사, 과한 애교, 긴 설명

## 프롬프트 태그 (고정)

# 3. 에스텔 (Estelle) — 숲의 마녀

- 27세 / 171cm / 동쪽 숲의 약초 마녀
- **머리**: 은빛이 도는 금발 / 밝은 애시 블론드. 긴 머리. 느슨하게 흘러내림
- **눈**: 금빛. 빛에 따라 녹갈색으로 보임 (허용)
- **얼굴**: 우아하고 나른하지만 **지적인** 느낌. 눈매가 살짝 처져 여유로워 보임
- **모자**: **넓은 챙의 보랏빛 마녀 모자. 숲의 야생화가 챙에 꽂혀 있음** (필수 시그니처)

- **체형**: 키가 크고 균형 잡힌 성인 체형. 어깨가 편안히 열려 있음

## 캐릭터 방향성 (가장 중요)

- 날카로운 rogue / 암살자 / 후드 뒤집어쓴 실루엣 금지

# 7. 캐릭터 일관성 운영 규칙

## 7-1. 시드 / 레퍼런스 고정
각 캐릭터는 **고정 시드 + 기준 이미지**를 1세트 확정한 뒤 바꾸지 않는다.
`01_references/seeds.json` 에 기록:
```json
{
  "marie":   {"seed": null, "sheet": "marie_sheet.png",   "ipa_weight": 0.75},
  "anna":    {"seed": null, "sheet": "anna_sheet.png",    "ipa_weight": 0.80},
  "estelle": {"seed": null, "sheet": "estelle_sheet.png", "ipa_weight": 0.75},
  "berta":   {"seed": null, "sheet": "berta_sheet.png",   "ipa_weight": 0.70},
  "else":    {"seed": null, "sheet": "else_sheet.png",    "ipa_weight": 0.65},
  "boy":     {"seed": null, "sheet": "boy_sheet.png",     "ipa_weight": 0.65}
}
```
> 안나의 ipa_weight를 가장 높게 둔다 — 체형이 가장 쉽게 드리프트하기 때문.

## 7-2. 컷 생성 체크 3종
모든 컷에서 아래 3개를 눈으로 확인한다.
1. **머리색 + 눈색** 일치
2. **의상 색 + 베일 패턴** 일치
3. **체형 실루엣** 일치 (특히 안나)

## 7-3. 2인 이상 등장 컷
- 키 차이를 먼저 확인 (에스텔 > 안나 > 베르타 > 마리 > 엘제)
- 한 컷에 두 캐릭터가 모두 정면을 보는 구도 반복 금지
- 가능하면 **한 명은 등/어깨, 한 명은 얼굴** 로 깊이를 만든다
