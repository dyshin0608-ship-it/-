# PAGE LAYOUT RULES — 컷 분할 / 패널 설계 규칙

---

## 1. 페이지 규격

| 항목 | 값 |
|---|---|
| 작업 해상도 | 1536 × 2304 px (2:3) |
| 납품 해상도 | 2048 × 3072 px |
| 외곽 여백 (bleed-safe) | 상하좌우 각 72px |
| 패널 간격 (gutter) | 세로 24~32px / 가로 20~28px (불균일 허용) |
| 페이지 배경 | 종이 질감 크림색 `#E8E2D4` (완전 흰색 금지) |

---

## 2. 컷 크기 등급

| 등급 | 면적 비율 | 용도 |
|---|---|---|
| **XL** | 페이지의 1/2 이상 | 하이라이트: 감정 폭발 / 발견 / 중요 대사 / 첫 등장 / 분위기 확립 |
| **L** | 약 1/3 | 준하이라이트, 2인 관계 컷 |
| **M** | 약 1/5 | 일반 대사 컷 |
| **S** | 1/8 이하 | 인서트: 손, 발, 소품, 시선, 약초, 책, 흔적 |

### 2-1. 페이지당 할당
- XL: **1개 필수, 최대 2개**
- L: 1~2개
- M: 2~4개
- S: 1~4개
- **총 5~9컷.** 10컷 넘으면 숨이 막히고, 4컷 이하면 리듬이 죽는다

### 2-2. 하이라이트 판정 체크
아래 중 하나라도 해당하면 **XL 또는 L**로 올린다.
- [ ] 캐릭터 첫 등장
- [ ] 감정이 바뀌는 순간
- [ ] 관객이 **처음 보는** 정보 (실제 꽃, 비교 컷)
- [ ] 1화 주제를 담은 대사
- [ ] 장소가 바뀌는 첫 컷
- [ ] 나중에 회상으로 다시 쓸 컷

> **중요한 장면을 작은 컷으로 끝내면 설계 실패다.**

## 3. 패널 형태

### 3-1. 기본
- 손으로 그린 테두리. **자로 그은 직선 금지**
- 선에 필압 변화 (굵기 0.8~2.4px 사이 변동)
- 각 변이 1~3px 정도 흔들림. 과하면 지저분해짐
- 모서리는 완전한 직각이 아님 (±2°)

### 3-2. 변형 허용
| 형태 | 사용처 |
|---|---|
| 손으로 찢은 듯한 테두리 | 회상, 플래시백 (p007-3, p009-6) |
| 테두리 없는 블리드 컷 | 분위기 확립, 전경 (p005-1, p010-5) |
| 비정형 사각 (약간 기울어짐) | 긴장/불안 (p008-1~4) |
| 원형/타원 소프트 마스크 | 시선 집중 인서트 (드물게, 페이지당 최대 1) |
| 컷 밖으로 삐져나오는 피사체 | 강조 (손, 꽃) — 페이지당 최대 1 |

### 3-3. 금지
- 정사각형/직사각형 균일 그리드 반복
- 3×3 균등 분할
- 모든 컷이 같은 폭
- 패널 사이 간격이 전부 똑같음

---

## 4. 읽는 순서 (가장 중요)

### 4-1. 기본 흐름
**좌 → 우, 상 → 하** (한국 웹툰/단행본 공통). Z자 흐름.

### 4-2. 보장 규칙
1. 한 행(row)에 3컷 이상 두지 않는다 (2컷 권장)
2. 행 경계는 **페이지 폭 전체를 가로지르는 간격**으로 명확히 끊는다
3. 대형 컷 옆에 작은 컷 2개를 세로로 쌓을 때는, 작은 컷이 **같은 폭**을 공유해 묶음임을 보여준다
4. 세로로 긴 컷과 가로로 긴 컷이 L자로 맞물리는 구조는 **페이지당 최대 1회**
5. 대사 순서 = 컷 순서. 말풍선이 읽는 순서를 역행하면 레이아웃 수정

### 4-3. 검수 방법
> 완성 페이지를 **1/4 크기로 축소**해서 본다.
> 눈이 자연스럽게 1→2→3…으로 흐르지 않으면 재설계.

---

## 5. 샷 다양성 규칙

### 5-1. 필수 혼합 (페이지당 최소 4종)
ELS / LS / FS / MS / BS / CU / ECU / OTS / TOP / LOW / HIGH / INS

### 5-2. 금지 패턴
| 금지 | 이유 |
|---|---|
| BS 2연속 | 대화가 정적인 TV 드라마처럼 보임 |
| 같은 캐릭터 CU 2연속 | 감정이 눌리지 않고 늘어짐 |
| 같은 앵글 3연속 | AI 템플릿 느낌 |
| 한 페이지 전체가 눈높이 샷 | 깊이가 없음 |
| 마리가 계속 숙인 자세 | 캐릭터가 죽음 |
| 안나가 계속 고개 들고 말하는 반신샷 | **명시 금지 사항** |
| 에스텔이 계속 같은 자세 | **명시 금지 사항** — 씬당 자세 최소 2회 변경 |

### 5-3. 정적 대화 씬 변주법
대사가 많아 컷이 정적일 때, 아래로 변화를 만든다.
1. **거리 변화** — MS → CU → LS 로 카메라가 들어가거나 빠진다
2. **손** — 손짓, 쥐기, 멈춤, 만지기
3. **시선** — 피함 / 마주봄 / 다른 데를 봄
4. **소품** — 붓, 스케치북, 꽃, 바구니, 열쇠
5. **기대기/앉기/걷기** — 몸의 축을 바꾼다
6. **등/어깨** — 한 명을 뒷모습으로
7. **오버숄더** — 상대의 어깨 너머로
8. **환경** — 빛의 각도, 바람, 먼지

## 6. 2인 이상 컷 설계

- 두 캐릭터가 **모두 정면**을 보는 구도 반복 금지
- 가능하면 **한 명은 등/어깨, 한 명은 얼굴** → 깊이 생성
- **키 차이를 반드시 반영**: 에스텔(171) > 안나(162) > 베르타(165는 안나보다 큼: 베르타 > 안나) > 마리(158) > 엘제(155)
  - 정렬: 에스텔 171 > 베르타 165 > 안나 162 > 마리 158 > 엘제 155 > 소년 142
- 3인 컷(p010-4)은 **삼각 배치**. 일렬 금지

## 8. 페이지 검수 체크 (레이아웃)

- [ ] XL 컷이 1개 이상 있는가
- [ ] 총 컷 수가 5~9인가
- [ ] 한 행에 3컷 초과가 없는가 (인서트 3연타 제외)
- [ ] 샷 종류가 4종 이상인가
- [ ] BS 2연속이 없는가
- [ ] 패널 테두리가 손그림인가 (자로 그은 직선 아님)
- [ ] 1/4 축소 시 읽는 순서가 자연스러운가
- [ ] 대사 순서와 컷 순서가 일치하는가
- [ ] 균일 그리드가 아닌가
- [ ] 무대사 컷이 최소 1개 있는가
