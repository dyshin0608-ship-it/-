# SPEECH BUBBLE RULES — 말풍선 / 텍스트 규칙

> **대원칙: 텍스트는 AI 이미지에 직접 생성하지 않는다.**
> 그림은 textless로 생성하고, 한국어 텍스트는 **후처리 레이어**로 합성한다.

---

## 1. 왜 후처리인가

| AI 직접 생성 | 후처리 합성 |
|---|---|
| 한글이 뭉개짐 / 글자가 깨짐 | 폰트가 또렷함 |
| 오타·맞춤법 틀림 | 원문 그대로 |
| 수정 시 이미지 재생성 | 텍스트만 수정 |
| 말풍선 꼬리가 엉뚱한 곳 | 꼬리 좌표를 지정 |
| 번역·다국어 불가 | JSON만 교체 |

→ **예외 없음.** 효과음(의성어)조차 후처리를 기본으로 한다.

---

## 2. 생성 단계에서 해야 할 일 (Bubble Safe Area)

### 2-1. 프롬프트에 포함
```
textless, no text, no letters, no speech bubbles,
composition with clear empty negative space in the upper third for text overlay
```

### 2-2. 안전영역 확보 원칙
- 각 컷에서 **대사가 들어갈 구역을 비워 둔다** (하늘, 벽, 어두운 배경, 흐린 전경)
- 안전영역은 컷 면적의 **15~30%**
- 캐릭터 얼굴 위에 말풍선이 겹치면 안 되므로, **얼굴 위쪽 또는 반대편 어깨 쪽**을 비운다
- 대사 2줄 이상인 컷은 안전영역을 더 크게
- 안전영역 위치는 `06_prompts/dialogue/page_0XX.json` 의 `safe_zone` 필드에 기록

### 2-3. 컷별 안전영역 지정 예
| 컷 | 대사량 | 안전영역 |
|---|---|---|
| p001-5 (안나 BS) | 3줄 | 상단 좌측 (창빛 배경) |
| p002-7 (XL 2인) | 2줄 | 상단 전체 (어두운 벽) |
| p006-8 (에스텔 XL) | 1줄 | 상단 우측 (숲 상부, 흐린 나뭇잎) |
| p010-5 (ELS 전경) | 내레이션 3줄 | **하단 전체 — 캡션 박스용** |

## 3. 말풍선 디자인

### 3-1. 기본 사양
| 항목 | 값 |
|---|---|
| 형태 | 손으로 그린 타원. 완전한 원/타원 금지 |
| 테두리 | 손그림 선, 굵기 2.5~3.5px, 필압 변화 있음 |
| 테두리 색 | `#241E18` (진한 갈색-검정) |
| 배경 색 | `#FDFBF4` (아주 옅은 크림) — 순백 `#FFFFFF` 금지 |
| 배경 불투명도 | 96~100% (살짝 종이가 비치게) |
| 내부 여백 | 텍스트 박스 기준 상하 18px / 좌우 22px |
| 그림자 | 없음 (또는 2px 옵셋의 아주 연한 종이 그림자) |

### 3-2. 종류별
| 종류 | 형태 | 용도 |
|---|---|---|
| **일반** | 손그림 타원 + 삼각 꼬리 | 보통 대사 |
| **작은 소리 / 흐림** | 점선 테두리 타원 | "…네." / "…그렇군요." 같은 흐린 대사 |
| **오프 보이스** | 타원 + 컷 밖으로 나가는 꼬리 | p006-7 에스텔(오프) |
| **생각** | 구름형 + 동글 꼬리 3개 | 1화에서는 사용 안 함 |
| **내레이션 캡션** | **사각 박스**, 모서리 손그림, 반투명 크림 | p010-5 마리(N) 3줄 |
| **강조** | 테두리 굵게 (4px) + 약간 큰 글자 | "틀린 그림을 보고 틀린 풀을 캐면, 사람이 죽어." |

### 3-3. 꼬리 (가장 중요)
- **꼬리는 화자의 입 또는 얼굴을 명확히 가리킨다**
- 꼬리 끝과 화자 얼굴의 거리: 컷 짧은 변의 **15% 이내**
- 화자가 컷 밖이면 꼬리를 **컷 경계 밖으로** 뺀다
- 한 컷에 2인 대사가 있으면:
  - 말풍선을 **각자의 머리 쪽**에 배치
  - 읽는 순서가 좌→우, 위→아래가 되도록 **먼저 말하는 쪽을 위/왼쪽**
  - 두 말풍선이 겹치지 않게 (최소 간격 16px)
- **금지**: 꼬리 없는 말풍선, 애매한 중간 위치, 꼬리가 다른 캐릭터를 가리킴

## 4. 타이포그래피

### 4-1. 폰트
| 용도 | 폰트 | 비고 |
|---|---|---|
| 1순위 본문 | **나눔바른고딕** 또는 **Pretendard** | 가독성 최우선 |
| 2순위 본문 | 나눔고딕 / 노토산스 KR | |
| 대안 (손글씨 느낌) | **나눔손글씨 고딕아씨** / 배민 주아체 | 과하면 금지 |
| 내레이션 | 본문과 동일 폰트의 **Light/Regular**, 자간 +4% | 구분 |
| 강조 | 본문 폰트 **Bold** | 별도 폰트 추가 금지 |

**금지 폰트 특성**: 너무 얇음(Thin/ExtraLight), 과도한 장식, 필기체, 세리프 과다

> 폰트 파일은 `assets/fonts/` 에 둔다. 상업 이용 라이선스 확인 필수
> (나눔·Pretendard·노토는 상업 이용 가능, 배민체는 조건 확인).

### 4-2. 크기 (1536×2304 페이지 기준)
| 용도 | 크기 | 행간 |
|---|---|---|
| 일반 대사 | 34~38px | 1.45 |
| 작은 소리 | 28~30px | 1.4 |
| 강조 대사 | 42~46px | 1.4 |
| 내레이션 | 32~34px | 1.6 |
| 효과음 | 48~80px (수동 배치) | — |

> **최소 크기 28px 사수.** 모바일에서 읽히지 않으면 전부 실패.

### 4-3. 색
- 글자: `#1F1A14` (진한 갈색-검정) 또는 `#14181F` (남청-검정)
- 순수 검정 `#000000` 금지 (종이 느낌을 깨뜨림)
- 강조 대사도 색을 바꾸지 않는다 (굵기로만 강조)

### 4-4. 줄바꿈
- **의미 단위로 끊는다.** 문법 단위 중간에서 끊지 않음
  - O: `두려운 대상일수록 더 알고 싶고…` / `더 그리고 싶어지거든요.`
  - X: `두려운 대상일수록 더 알고` / `싶고… 더 그리고 싶어지거든요.`
- 한 줄 최대 **14자** (일반 대사)
- 한 말풍선 최대 **3줄**. 넘으면 말풍선을 나눈다
- 말풍선 모양은 텍스트 블록에 맞춘다 (텍스트가 말풍선에 맞추는 게 아님)

## 5. 캐릭터별 말투 (텍스트 검수용)

| 캐릭터 | 말투 | 체크 |
|---|---|---|
| **마리** | 조용·짧음·신중. 존댓말. 감정 절제 | 긴 문장이 나왔다면 의심 |
| **안나** | 부드럽고 친근. 호기심. 존댓말. 물음표 많음 | 꼬시는 느낌이면 수정 |
| **에스텔** | **반말 고정.** 차분, 약간 장난스럽지만 가볍지 않음 | **존댓말 1개라도 발견 시 전체 재검수** |
| **베르타** | 짧고 단호. 평서문 | 설명이 길면 수정 |
| **엘제** | 투박한 생활어. 아주 짧게 | |
| **소년** | 순박. 존댓말. 말끝 흐림 | |

### 5-1. 공통 금지
- 설명충 대사 (정보를 대사로 쏟아내기)
- 과한 문어체
- 캐릭터에 안 맞는 말투
- 감탄사 남발 ("와!", "어머!")
- 나레이션으로 상황을 설명하기 (p010 엔딩 3줄만 예외)

## 7. 후처리 워크플로우

```
04_textless_pages/page_001.png        ← 텍스트 없는 완성 페이지
06_prompts/dialogue/page_001.json     ← 대사 + 좌표 + 꼬리 + 스타일
          ↓  tools/add_bubbles.py
05_final_pages/page_001.png           ← 최종
```

### 7-1. 대사 JSON 스키마
```json
{
  "page": 1,
  "canvas": [1536, 2304],
  "bubbles": [
    {
      "id": "p001-b01",
      "panel": 5,
      "speaker": "안나",
      "type": "normal",
      "lines": ["마리 수녀님,", "이 풀 이름이 뭐라고요?"],
      "box": [140, 980, 520, 160],
      "tail_to": [430, 1180],
      "font_size": 36,
      "align": "left"
    }
  ],
  "captions": []
}
```
- `box`: `[x, y, w, h]` — 텍스트 블록 영역 (말풍선은 여기서 자동 팽창)
- `tail_to`: 화자의 입/얼굴 좌표. **반드시 지정**
- `type`: `normal` | `soft` | `off` | `emphasis` | `caption` | `sfx`

### 7-2. 도구 선택지
| 방법 | 장점 | 추천도 |
|---|---|---|
| **Python + Pillow** (`tools/add_bubbles.py`) | 자동화, 버전 관리, 일괄 수정 | ★★★ 기본 |
| Krita | 무료, 레이어, 손그림 말풍선 | ★★★ 수동 보정 |
| Clip Studio Paint | 말풍선 도구 최강, 한국어 조판 | ★★★ 예산 있으면 |
| GIMP + Script-Fu | 무료 | ★★ |
| Photoshop PSD | 익숙함 | ★★ |

**권장 하이브리드**: Pillow로 1차 일괄 배치 → Krita/CSP에서 손그림 테두리·꼬리 다듬기

## 8. 텍스트 검수 체크리스트

### 8-1. 오타·맞춤법
- [ ] 전체 대사를 **소리 내어 읽어** 확인
- [ ] 맞춤법 검사기 통과 (부산대 한국어 맞춤법 검사기 등)
- [ ] 말줄임표는 `…` (U+2026) 통일. `...` 금지
- [ ] 따옴표·쉼표 전각/반각 통일
- [ ] 캐릭터 이름 표기 통일 (마리 / 안나 / 에스텔 / 베르타 / 엘제)

### 8-2. 조판
- [ ] 글자가 말풍선 밖으로 나가지 않음
- [ ] 글자가 말풍선 테두리에 닿지 않음 (여백 18/22px)
- [ ] 최소 폰트 28px 이상
- [ ] 줄바꿈이 의미 단위
- [ ] 한 말풍선 3줄 이하

### 8-3. 꼬리·순서
- [ ] 모든 말풍선에 꼬리가 있음 (캡션 제외)
- [ ] 꼬리가 화자를 명확히 가리킴
- [ ] 한 컷 2인 대사 시 읽는 순서가 맞음
- [ ] 말풍선이 캐릭터 얼굴을 가리지 않음
- [ ] 말풍선이 하이라이트 컷의 핵심 피사체를 가리지 않음
- [ ] 말풍선끼리 겹치지 않음

### 8-4. 말투
- [ ] **에스텔 대사에 존댓말이 없음** (최우선)
- [ ] 마리 대사가 짧고 절제됨
- [ ] 안나 대사가 꼬시는 느낌이 아님
- [ ] 설명충 대사 없음
