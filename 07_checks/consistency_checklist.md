# CONSISTENCY CHECKLIST — 일관성 / 품질 검수

> 사용법: 컷 생성 시 **A**, 페이지 완성 시 **B~E**, 에피소드 완료 시 **F** 를 돌린다.
> 하나라도 ✗ 면 **재생성**. "예쁘니까 넘어가자"가 스타일 붕괴의 시작이다.

---

# A. 컷 단위 체크 (72컷 전부, 생성 직후 10초)

## A-1. 3종 즉시 확인
- [ ] **머리색 + 눈색** 이 바이블과 일치
- [ ] **의상 색 + 베일 패턴** 이 일치
- [ ] **체형 실루엣** 이 일치 (특히 안나)

## A-2. 캐릭터별 치명 항목
| 캐릭터 | 확인 | ✗면 |
|---|---|---|
| 마리 | 흑발 / 호박빛 눈 / 날씬 / 청초 / 손에 잉크 자국 | 재생성 |
| 마리 | 표정이 과장되지 않았는가 (입 크게 벌림 금지) | 재생성 |
| 안나 | **충분히 풍만한가** | 재생성 |
| 안나 | 노골적·선정적이지 않은가 / 옷이 밀착되지 않았는가 | 재생성 |
| 안나 | 금발 / 곱슬 / 둥근 얼굴 / 발간 볼 | 재생성 |
| 에스텔 | **도적처럼 보이지 않는가** | 재생성 |
| 에스텔 | 모자에 야생화가 있는가 / 보랏빛인가 | 재생성 |
| 에스텔 | 후드·단검·가죽벨트 다중·복면이 없는가 | 재생성 |
| 베르타 | 검은 수도복 / 나무 십자가 / 열쇠 / **왼손 흉터**(왼손 컷) | 재생성 |
| 엘제 | 마른 체형 / 거친 손 | 수정 또는 허용 |
| 소년 | 12세 전후로 보이는가 / 바구니 | 재생성 |

## A-3. 스타일
- [ ] 붓자국이 보인다
- [ ] 종이 질감이 있다
- [ ] 번들거리지 않는다 (플라스틱·에어브러시 아님)
- [ ] 3D 렌더처럼 보이지 않는다
- [ ] 실사처럼 보이지 않는다
- [ ] 선이 딱딱한 디지털 선화가 아니다
- [ ] 색감이 해당 장소 팔레트와 맞는다

## A-4. 기본 결함
- [ ] 손가락 개수가 정상 (5개)
- [ ] 팔·다리 개수가 정상
- [ ] 눈이 비대칭이거나 사시가 아님
- [ ] **글자가 들어가지 않았다**
- [ ] 워터마크·서명이 없다

## A-5. 2인 이상 컷 추가
- [ ] 키 차이가 맞는다 (에스텔171 > 베르타165 > 안나162 > 마리158 > 엘제155 > 소년142)
- [ ] 두 얼굴이 섞이지 않았다
- [ ] 둘 다 정면을 보는 구도가 아니다 (한 명은 등/어깨)
- [ ] 3인 컷은 삼각 배치다 (일렬 아님)

# B. 페이지 레이아웃 체크 (페이지 완성 시)

- [ ] XL 컷이 1개 이상 있다
- [ ] 총 컷 수가 5~9이다
- [ ] 한 행에 3컷 초과가 없다 (인서트 3연타 제외)
- [ ] 샷 종류가 4종 이상 섞였다
- [ ] **BS 2연속이 없다**
- [ ] 같은 캐릭터 CU 2연속이 없다
- [ ] 같은 앵글 3연속이 없다
- [ ] 패널 테두리가 손그림이다 (자로 그은 직선 아님)
- [ ] 균일 그리드가 아니다
- [ ] 무대사 컷이 최소 1개 있다
- [ ] 페이지 배경이 종이 질감 크림색이다 (순백 아님)

## B-1. 하이라이트 배치
- [ ] 하이라이트 장면이 XL/L로 배치되었다
- [ ] **중요한 장면이 작은 컷으로 끝나지 않았다**
- [ ] 연결·설명 컷이 S/M으로 배치되었다

## B-2. 읽는 순서 (★ 가장 중요)
- [ ] **1/4 크기로 축소**해서 봤을 때 눈이 자연스럽게 흐른다
- [ ] 행 경계가 명확하다
- [ ] 대사 순서 = 컷 순서
- [ ] 말풍선이 읽는 순서를 역행하지 않는다

# C. 말풍선 / 텍스트 체크 (STEP 8 직후)

## C-1. 오타·맞춤법
- [ ] 전체 대사를 **소리 내어 읽어** 확인했다
- [ ] 맞춤법 검사기를 통과했다
- [ ] 말줄임표가 `…` (U+2026) 로 통일되었다
- [ ] 글자가 뭉개지거나 깨지지 않았다
- [ ] 캐릭터 이름 표기가 통일되었다

## C-2. 조판
- [ ] 글자가 말풍선 밖으로 나가지 않았다
- [ ] 글자가 테두리에 닿지 않았다 (여백 18/22px)
- [ ] 폰트 크기가 28px 이상이다
- [ ] 줄바꿈이 의미 단위다
- [ ] 한 말풍선이 3줄 이하다
- [ ] 폰트가 너무 얇거나 장식적이지 않다
- [ ] 말풍선 배경이 순백이 아니다 (크림색)
- [ ] 글자색이 순수 검정이 아니다

## C-3. 꼬리 / 화자 (★)
- [ ] 모든 말풍선에 꼬리가 있다 (캡션 제외)
- [ ] **꼬리가 화자를 명확히 가리킨다**
- [ ] 화자가 컷 밖이면 꼬리가 컷 경계 밖으로 나갔다
- [ ] 한 컷에 2인 대사 시 읽는 순서가 맞다
- [ ] 말풍선이 캐릭터 얼굴을 가리지 않는다
- [ ] 말풍선이 하이라이트 컷의 핵심 피사체를 가리지 않는다
- [ ] 말풍선끼리 겹치지 않는다 (간격 16px 이상)
- [ ] **누가 말하는지 헷갈리는 말풍선이 하나도 없다**

## C-4. 말투
- [ ] **에스텔 대사에 존댓말이 없다** ← 최우선
- [ ] 마리 대사가 짧고 절제되었다
- [ ] 안나 대사가 꼬시는 느낌이 아니다
- [ ] 베르타 대사가 짧고 단호하다
- [ ] 엘제 대사가 아주 짧다
- [ ] 소년 대사가 순박하고 말끝이 흐려진다
- [ ] **설명충 대사가 없다**
- [ ] 나레이션이 남발되지 않았다 (p010 3줄만)
- [ ] 학술 용어(설상화/통상화 등)가 대사에 없다

## C-5. 내레이션 / 캡션
- [ ] p010-5 내레이션이 **사각 캡션 박스**다 (말풍선 아님)
- [ ] 캡션에 꼬리가 없다
- [ ] 캡션이 본문과 구분되는 서체 웨이트다

# D. 스타일 드리프트 체크 (페이지 간)

- [ ] **직전 페이지와 그림체가 같다**
- [ ] 같은 장면(씬) 내에서 색온도가 통일되었다
- [ ] 캐릭터 얼굴이 직전 페이지와 같은 사람이다
- [ ] 의상 색이 변하지 않았다
- [ ] 선의 성격이 변하지 않았다
- [ ] 질감의 밀도가 변하지 않았다

## D-1. 대조 검수 (필수)
완성 페이지를 **직전 페이지와 나란히** 놓고 본다.
- [ ] p001 ↔ p002
- [ ] p002 ↔ p003
- [ ] p003 ↔ p004
- [ ] p004 ↔ p005
- [ ] p005 ↔ p006
- [ ] p006 ↔ p007
- [ ] p007 ↔ p008
- [ ] p008 ↔ p009
- [ ] p009 ↔ p010

## D-2. 캐릭터 전체 대조
각 캐릭터가 등장하는 **모든 컷을 한 화면에 모아** 본다.
- [ ] 마리 (등장: p001~p010 거의 전부)
- [ ] 안나 (등장: p001, p003~p010)
- [ ] 에스텔 (등장: p006~p010)
- [ ] 베르타 (등장: p002)

# E. 1화 전용 대조 검수 (★★ 주제 검증)

이 세 컷을 **반드시 나란히 놓고** 본다. 1화의 주제가 성립하는지가 여기서 결정된다.

| 컷 | 내용 | 확인 |
|---|---|---|
| **p001-4** | 마리가 그린 도해 — 꽃잎 **다섯 장** | [ ] 또렷하게 다섯 장으로 보인다 |
| **p005-5** | 실제 쑥부쟁이 — 설상화 **수십 장** | [ ] 셀 수 없이 많아 보인다 |
| **p009-4** | 두 풀 비교 — 차이가 보임 | [ ] 잎·줄기·꽃 중심의 차이가 눈으로 구분된다 |

- [ ] 세 컷의 **구도가 비교 가능하게** 맞춰져 있다 (정면 평면)
- [ ] p001-4 와 p005-5 를 번갈아 보면 **"책이 틀렸다"** 가 느껴진다
- [ ] p009-4 를 보면 **"잘못 캐면 위험하다"** 가 느껴진다

> 이 세 컷이 실패하면 1화는 성립하지 않는다. 다른 컷을 포기하고라도 이 세 컷에 시간을 쓴다.

## E-1. 1화 복선 심기 확인
- [ ] p002-4 — 베르타 왼손 화상 흉터가 보인다
- [ ] p006-4 — 나뭇가지의 보라색 실이 보인다
- [ ] p004-1 — 안나의 "다시는 가지 않겠다" 대사가 들어갔다
- [ ] p010-5 — "아직 이름 붙지 않은 진실" 내레이션이 들어갔다

## E-2. 1화 감정 아크 확인
- [ ] 안나가 p006-8에서 **물러나고**, p010-4에서 **나아간다** (대조 성립)
- [ ] 마리가 p010-1에서 **처음으로 먼저 말한다**
- [ ] 에스텔이 p008-6에서 **처음으로 표정이 바뀐다**
- [ ] 베르타가 p002에서 **답을 주지 않는다**
