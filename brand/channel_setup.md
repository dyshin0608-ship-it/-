```
현실도 결국 RPG입니다.

## EP1 제목 — RPG 톤으로 다시

기존 다큐 톤 제목은 채널 컨셉과 어긋납니다. 아래로 바꾸는 게 맞습니다.

**추천**
```
승진할수록 일당이 깎입니다 | 건설 안전관리자 1~4레벨 공략
```

**대안**
```
안전관리자 레벨 1~4 공략 | 일당 15만 → 11만 → 20만
```
```
레벨 3까지 올렸는데 월급이 줄었습니다 | 건설 안전 계급도
```

> 영상 화면이 이미 "1칸 / 2칸 / 3칸 / 4칸"에 사다리 표시라서 레벨 개념과 그대로 맞습니다.

## EP1 설명란 — RPG 톤 (그대로 복사)

```
건설 현장 안전직은 열 칸짜리 사다리입니다.
이번 편에서는 아래 네 칸을 올라갑니다.

이상한 건, 세 칸을 올라가는 동안 일당이 15만 → 13만 → 11만으로
오히려 줄어든다는 겁니다. 그러다 네 번째 칸에서 20만 원대로 뜁니다.

차이는 서류 한 장. 안전관리자 선임보고서에 이름이 올라가느냐입니다.
넷 중 셋은 법적으로 안전관리자가 아닙니다.

자격증 없이 현장에 들어온 준호가 어디까지 갈 수 있는지 따라갑니다.

── 공략 순서 ──
00:00 같은 안전모, 다른 계급
00:52 레벨을 가르는 기준 : 공사금액
01:24 Lv.1 안전감시원
02:20 Lv.2 안전감시단
03:35 Lv.3 작은 현장 안전 담당
05:26 Lv.4 법정 안전관리자
06:58 다음 편 예고

── 확인한 것 ──
2025년 1분기 건설 사고사망자 71명 중 39명이 공사금액 50억 미만
현장에서 나왔습니다. 작은 현장일수록 안전관리자 선임 의무가 없습니다.

급여와 근무 조건은 채용 공고 기준이며 현장·회사에 따라 다릅니다.
법령 해석이 필요한 사안은 전문가 상담을 권합니다.

```

```
